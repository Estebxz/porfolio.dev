## ⭐️ Resumen
Pagina web personalizada para mostrar en general mis proyectos, conocimientos, se puede utilizar de forma gratuita si se indica al creador.

## 🖥️ Desarrollo Local:
> [!IMPORTANT]
> Necesita tener instalado [**Bun**](https://bun.sh/)

1. Clone el repositorio:

```bash
git clone https://github.com/Estebxz/porfolio.dev.git
```

2. Entre en el repositorio:

```bash
cd porfolio.dev
```

3. Instale las dependencias:

```bash
bun install
```

4. Configure el archivo .env:

```bash
# Linux/MacOS:
cp .env.example .env

# Windows:
copy .env.example .env
```

> [!NOTE]
> Recuerde establecer correctamente las credenciales correspondientes en el archivo **.env** si requiere un buen funcionamiento del _backend_, de lo contrario solamente renderizará el _frontend_.

5. Inicie el servidor en modo desarrollo:

```bash
bun run dev
```

6. Abra el navegador en la siguiente URL:

→ [http://localhost:4321](http://localhost:4321)
